Push Button Controlled LED using ESP32
1. Introduction

This project demonstrates how to interface a push button with an ESP32 DevKit V1 to control an LED. The ESP32 continuously monitors the state of the push button. When the button is pressed, the LED turns ON, and when the button is released, the LED turns OFF. The project also introduces the use of the ESP32's internal pull-up resistor, eliminating the need for an external resistor.

2. Objectives
Understand digital input and output.
Interface a push button with ESP32.
Learn the purpose of INPUT_PULLUP.
Read digital signals using digitalRead().
Control an LED using conditional statements.

4. Circuit Description

GPIO 2 is configured as an output to drive the LED.

GPIO 4 is configured as an input using the ESP32's internal pull-up resistor.

When the push button is not pressed, GPIO 4 remains HIGH because it is internally connected to 3.3 V through a pull-up resistor.

When the button is pressed, GPIO 4 is directly connected to GND, causing the input to become LOW.

5. Program Explanation

The ESP32 continuously checks the button state using digitalRead().

If the button is pressed (LOW), the LED is turned ON.

If the button is released (HIGH), the LED is turned OFF.

6. Flow of Execution
Configure GPIO 2 as OUTPUT.
Configure GPIO 4 as INPUT_PULLUP.
Read GPIO 4.
If LOW → Turn LED ON.
Otherwise → Turn LED OFF.
Repeat continuously.
